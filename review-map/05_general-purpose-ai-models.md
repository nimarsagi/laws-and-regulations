# 05 — General-purpose AI models

Only when the PRD trains, fine-tunes or releases a model for others to build on. A PRD that only calls a model through an API isn't a model provider; skip to [10](10_vendors-and-transfers.md) for what it can expect from the model's maker.

1. **Is it a general-purpose model?** [AI Act Art 3(63)](../ai-act/ch-01_general-provisions/art-003.md). **With systemic risk?** [Art 51](../ai-act/ch-05_general-purpose-ai-models/art-051.md) (threshold in 51(2)), notification [Art 52](../ai-act/ch-05_general-purpose-ai-models/art-052.md).
2. **Provider duties:** [Art 53(1)](../ai-act/ch-05_general-purpose-ai-models/art-053.md): (a) technical documentation ([Annex XI](../ai-act/annexes/annex-11.md)), (b) information for those building on it ([Annex XII](../ai-act/annexes/annex-12.md)), (c) a copyright policy, (d) a public summary of training content. Open-source models are spared (a) and (b): 53(2). Non-EU providers need an EU representative: [Art 54](../ai-act/ch-05_general-purpose-ai-models/art-054.md).
3. **Systemic-risk duties:** evaluation, risk reduction, incident reporting, security: [Art 55](../ai-act/ch-05_general-purpose-ai-models/art-055.md). Codes of practice as a way to show compliance: [Art 56](../ai-act/ch-05_general-purpose-ai-models/art-056.md).

## Watch
- Applies since 2 Aug 2025; models on the market before then have until 2 Aug 2027: [Art 111(3)](../ai-act/ch-13_final-provisions/art-111.md). Fines for model providers: [Art 101](../ai-act/ch-12_penalties/art-101.md).
- Fine-tuning someone else's model can make you the provider of the changed model. The Act's text doesn't settle how much change that takes; mark it **decide**.
